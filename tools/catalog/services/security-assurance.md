# Certificación, auditoría y garantía de seguridad

- **ID de categoría:** `CAT-SECURITY`
- **Estado:** `proposed`
- **Política económica:** `pending-consensus`

## Servicios potenciales

- Pruebas de resistencia a identidades Sybil y nodos falsos.
- Simulaciones autorizadas de particiones, aislamiento Eclipse y colusión bizantina.
- Revisión de controles de claves, privilegios, pools y límites de recursos.
- Auditoría de configuraciones y pruebas de conformidad reproducibles.
- Preparación de informes técnicos y evidencias de evaluación.

## Requisitos de participación

Definir el alcance y obtener autorización por escrito antes de cualquier prueba ofensiva. Aislar laboratorios, registrar versiones y configuraciones, limitar carga y duración, proteger datos del cliente y documentar límites. Las pruebas no autorizadas contra terceros quedan excluidas.

## Evidencias y aceptación

Registrar plan de prueba, autorización, versión de herramientas, commit o artefacto evaluado, entradas, resultados, limitaciones, fecha y firma del evaluador. Aceptar el trabajo cuando se cumpla el plan aprobado y el informe sea reproducible dentro de las limitaciones declaradas.

## Límites

Un informe no equivale automáticamente a una acreditación internacional o a una garantía de ausencia de vulnerabilidades. El alcance de cada certificado debe ser explícito. La remuneración queda pendiente de consenso.
