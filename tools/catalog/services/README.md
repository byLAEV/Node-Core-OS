# Índice de productos y servicios

Las fichas de esta carpeta describen familias de servicios potencialmente monetizables. Son definiciones iniciales, no una declaración de disponibilidad comercial. Cada servicio concreto debe recibir un ID estable, criterios de aceptación y evidencias de implementación.

| Archivo | Categoría | Alcance inicial |
| --- | --- | --- |
| [identity-and-trust.md](identity-and-trust.md) | Identidad y confianza | Credenciales, firmas, verificación y atestaciones |
| [security-assurance.md](security-assurance.md) | Seguridad y auditoría | Evaluaciones, pruebas y certificados respaldados por evidencias |
| [network-and-consensus.md](network-and-consensus.md) | Red y consenso | Verificación de nodos, bloques, resiliencia y corroboración |
| [storage-and-content.md](storage-and-content.md) | Almacenamiento y contenido | Almacenamiento local, Kubo/IPFS, recuperación e integridad |
| [availability-and-compute.md](availability-and-compute.md) | Disponibilidad y cómputo | Monitorización de disponibilidad y tareas computacionales |
| [monitoring-and-supply-chain.md](monitoring-and-supply-chain.md) | Monitorización y cadena de suministro | Observabilidad, respuesta autorizada, procedencia y actualizaciones |

## Reglas comunes

- Estado inicial de estas familias: `proposed`.
- Política económica: `pending-consensus`.
- Ninguna ficha garantiza ingresos ni afirma disponibilidad de una función que no haya sido implementada y probada.
- La prueba de esfuerzo no sustituye la evidencia del resultado ni la aceptación del servicio.
- Cualquier prueba ofensiva debe estar autorizada y limitarse a sistemas de laboratorio o activos expresamente permitidos.
