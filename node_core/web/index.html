Seguridad y estado de implementación

La interfaz consulta el estado real de Kubo y permite iniciarlo mediante una acción explícita con confirmación. No expone la API RPC de Kubo al navegador ni detiene o reconfigura servicios.

El inicio de Kubo requiere confirmación explícita. Si el repositorio aún no está inicializado, KuboManager puede inicializarlo con el perfil configurado. Las demás operaciones que modifican el estado siguen pendientes.
