# Code of Conduct

## Our commitment

The Node Core OS project welcomes participation from people with different backgrounds, experience levels, and viewpoints. We aim to make collaboration respectful, practical, and focused on improving the software.

## Expected behavior

- Be respectful and constructive.
- Explain technical disagreements with evidence and reasoning.
- Accept good-faith feedback and review.
- Focus on the work, not personal attacks.
- Respect privacy and do not publish private information or credentials.
- Help keep discussions accessible to newcomers.

## Unacceptable behavior

Harassment, discrimination, threats, deliberate intimidation, personal attacks, doxxing, and repeated disruptive conduct are not acceptable.

## Maintainer response

Project maintainers may edit or remove inappropriate content, close discussions, or restrict participation when necessary to protect the community. Decisions should be proportionate to the behavior and project safety.

## Reporting

Report conduct concerns privately to the repository maintainers through a verified contact channel. Do not include sensitive personal information in public issues.

This code of conduct applies to project spaces and interactions undertaken in the name of the project.
