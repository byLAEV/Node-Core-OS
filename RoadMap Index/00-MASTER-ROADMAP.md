# 00 — Master Roadmap

Este documento concentra las líneas de trabajo identificadas para Node Core OS byLAEV que todavía requieren investigación, definición, implementación o validación.

Una entrada representa trabajo pendiente o una propuesta hasta que su estado y evidencia indiquen lo contrario.

## Registro de necesidades transversales

Estas áreas deberán convertirse en iniciativas específicas cuando se defina su alcance:

- [ ] Inventariar necesidades pendientes de arquitectura y operación del nodo.
- [ ] Inventariar necesidades de almacenamiento local.
- [ ] Inventariar necesidades de almacenamiento distribuido e integración IPFS/Kubo.
- [ ] Inventariar necesidades de APIs, protocolos y compatibilidad.
- [ ] Inventariar necesidades de seguridad, permisos, autenticación y auditoría.
- [ ] Inventariar necesidades de pruebas, instalación y compatibilidad Linux.
- [ ] Inventariar necesidades de documentación, mantenimiento y distribución.
- [ ] Registrar dependencias externas, servicios y permisos requeridos.

Las casillas anteriores son tareas de planificación, no afirmaciones de que esas capacidades estén ausentes o presentes. Cada una debe contrastarse con el repositorio antes de crear trabajo duplicado.

## Cómo actualizar este índice

1. Crear una iniciativa con ID único y documento propio.
2. Describir el estado real con enlaces a código, pruebas, documentación o fuentes.
3. Añadirla a la tabla de iniciativas.
4. Actualizar estado, prioridad, dependencias y fecha de revisión cuando haya cambios.
5. Marcar como VERIFIED solamente con criterios de aceptación y evidencia reproducible.
