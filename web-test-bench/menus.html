03My Life / Node BlogHistorial personal con control de publicación

03 · INSTALACIÓN GNU/LINUX

Qué hace el instalador

El instalador no tiene un menú gráfico interactivo propio: ejecuta una secuencia de pasos, comprueba los requisitos y termina con una verificación.

Importante: este recorrido representa el proceso real de instalación descrito en docs/INSTALLER.md. No es una captura de pantalla del instalador ni una interfaz que lo ejecute.
01

Comprobar plataforma

Confirma GNU/Linux y rechaza la ejecución como root.

→
02

Comprobar dependencias

Revisa Bash, Python y utilidades requeridas; no instala paquetes del sistema.

→
03

Preparar almacenamiento local

Prepara el directorio del usuario y la estructura de archivos de Node Core.

→
04

Instalar la aplicación

Copia el código de Node Core y verifica que Python pueda compilarlo.

→
05

Instalar y comprobar Kubo

Selecciona el binario compatible, verifica la descarga e inicializa el repositorio si corresponde.

→
06

Guardar configuración y launcher

Escribe la configuración y prepara el comando node-core.

→
07

Verificar la instalación

Comprueba Kubo, la API, los archivos de Node Core y el launcher antes de finalizar.
